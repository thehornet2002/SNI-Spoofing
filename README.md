# SNI Spoofing & TCP DPI Bypass Proxy

یک پروکسی بومی ویندوز جهت دور زدن فیلترینگ عمیق بسته‌ها (DPI) با استفاده از تکنیک‌های تزریق بسته در سطح درایور شبکه (**WinDivert** و **Npcap**).  
این ابزار به عنوان پل ارتباطی بین کلاینت شما (مانند **v2rayN**) و سرور/CDN مقصد قرار می‌گیرد و با ارسال بسته‌های جعلی و دستکاری هدرهای شبکه، فیلترچی را فریب داده و نشست (Session) را سفید می‌کند.

---

## 🚀 ویژگی‌های کلیدی

- **پنل گرافیکی ویندوزی (GUI):** مجهز به رابط کاربری مدرن (Dark Theme)، نشانگر وضعیت زنده اتصال، مدیریت لاگ‌ها و کلید Start/Stop.
- **تزریق مستقیم به کارت شبکه (Direct NIC via Npcap):** ارسال مستقیم بسته‌های جعلی به شکل فریم اترنت به درایور کارت شبکه فیزیکی با دور زدن کامل استک ویندوز و فایروال محلی.
- **پشتیبانی کامل از v2rayN:** سازگار با کانفیگ‌های `VLESS + WS + TLS` بدون نیاز به تغییر سرور.
- **پایداری بالا:** حذف کامل باگ‌های کرش (`sys.exit`)، آزادسازی صحیح سوکت‌ها، و عدم نیاز به ایجاد Thread به ازای هر اتصال.

## 🛠️ تکنیک‌های دور زدن فیلترینگ (Bypass Strategies)

هر یک از استراتژی‌های زیر را می‌توانید به صورت جداگانه یا همزمان از داخل پنل یا فایل کانفیگ فعال/غیرفعال کنید:

| استراتژی | توضیح فنی |
| :--- | :--- |
| **Wrong Seq** | ارسال ClientHello جعلی با دامنه مجاز و شماره توالی (Sequence) قبل از هندشیک، به طوری که DPI آن را قبول کند ولی سرور آن را بسته تکراری تشخیص دهد. |
| **Low TTL** | تزریق بسته جعلی با مقدار TTL پایین (مثلاً ۵). بسته توسط روترهای فیلترینگ داخلی خوانده شده ولی پیش از رسیدن به سرور مقصد از بین می‌رود (Drop). |
| **Wrong Checksum** | ارسال بسته جعلی با چک‌سام ناصحیح TCP؛ تجهیزات DPI برای جلوگیری از افت توان چک‌سام را چک نمی‌کنند، اما کرنل سرور آن را نادیده می‌گیرد. |
| **Fake RST (State Poisoning)** | شلیک یک پکت `TCP RST` جعلی با TTL پایین بلافاصله پس از هندشیک تا DPI تصور کند نشست بسته شده و ردیابی را متوقف کند. |
| **Protocol Confusion** | ارسال یک پروب ساده HTTP (`GET /`) پیش از شروع TLS در پورت ۴۴۳ تا DPI ترافیک را وب معمولی رده‌بندی کند. |
| **TLS SNI Fragmentation** | شکستن بسته واقعی TLS ClientHello دریافتی از v2rayN در مرز دامنه (SNI) یا هدر رکورد به دو یا چند سگمنت TCP مجزا با تاخیر چند میلی‌ثانیه‌ای. |
| **Fake ECH** | تزریق افزونه رمزنگاری‌شده Encrypted Client Hello (`0xfe0d`) داخل بسته ClientHello جعلی. |
| **TCP Overlap** | ارسال بسته جعلی با شماره توالی منطبق بر بازه داده‌های واقعی جهت بازنویسی کش جریان DPI. |

1. **ویندوز ۱۰ یا ۱۱** (۶۴ بیتی)
2. **پایتون:** نسخه ۳.۱۰ به بالا
3. **درایور Npcap:** نصب شده از طریق [وبسایت رسمی Npcap](https://npcap.com/) (گزینه "Install Npcap in WinPcap API-compatible Mode" انتخاب شده باشد).
4. **دسترسی Administrator:** جهت دسترسی درایورهای فیلترینگ و کارت شبکه، اجرای برنامه با Run as Administrator الزامی است.

## ⚙️ نحوه تنظیم در v2rayN

۱. برنامه **SNI Spoofing** را اجرا کرده و دکمه **START** را بزنید (سرویس به صورت پیش‌فرض روی `127.0.0.1:40443` آماده به کار می‌شود).  
۲. در برنامه **v2rayN** کانفیگ خود را ویرایش کنید:
   - فیلد **Address (آدرس سرور)** را روی `127.0.0.1` بگذارید.
   - فیلد **Port (پورت)** را روی `40443` بگذارید.
   - سایر فیلدها شامل **SNI** و **Host** مربوط به دامنه سرور خودتان بدون تغییر باقی می‌مانند.
۳. در تنظیمات `config.json` یا درون پنل برنامه:
   - مقدار `CONNECT_IP` را برابر با آی‌پی واقعی سرور یا آی‌پی تمیز کلودفلر خود قرار دهید.
   - مقدار `FAKE_SNI` را روی یک دامنه سفید داخلی (مثل `auth.vercel.com` یا `mci.ir`) بگذارید.


## ⚠️ نکات مهم

- برنامه همواره باید با دسترسی **Administrator** اجرا شود؛ در صورت اجرای معمولی، دکمه قرمز هشدار در پنل فعال شده و امکان ری‌استارت خودکار با دسترسی ادمین را در اختیارتان می‌گذارد.
- اگر اینترنت یا کارت شبکه سیستم تغییر کرد، سرویس را یک‌بار Stop و مجدداً Start کنید تا اینترفیس جدید به صورت پویا آدرس‌دهی شود.
- استراتژی‌های مختلف را با اپراتور اینترنت خود تست کنید؛ ترکیب **Wrong Seq + TLS Fragmentation** یا **Low TTL + Npcap Direct** در اکثر شبکه‌ها بالاترین پایداری را ارائه می‌دهد.
