# SNI Spoofing & TCP DPI Bypass Proxy

یک پروکسی چندمنظوره برای دور زدن فیلترینگ عمیق بسته‌ها (DPI) در پورت ۴۴۳ با تکنیک‌های تزریق بسته جعلی و هماهنگی با **v2rayN** و سایر کلاینت‌های مبتنی بر `VLESS + WS + TLS`.

پروژه به صورت خودکار از طریق **GitHub Actions (CI/CD)** برای هر دو سیستم‌عامل **Windows** و **Linux** بیلد و منتشر می‌شود.

---

## 🚀 ویژگی‌های کلیدی

- **پنل گرافیکی ویندوزی (GUI):**
  - مجهز به دارک تم مدرن، لاگ زنده اتصالات، دکمه‌های کنترلی Start/Stop و نشانگر وضعیت.
- **ترکیب تخصصی Sequence + Fake HTTP + Fake RST (۱۹۸ حالت):**
  - آزمودن ۲۴ آفست مختلف Sequence (کلاسیک، منفی، مثبت، و مطلق).
  - پروب‌های جعلی پروتکل (`HTTP GET` و `HTTP HEAD`).
  - مسموم‌سازی ماشین حالت فیلترچی با `Fake RST`.
  - تفکیک درایور سخت‌افزاری (`Npcap`) و نرم‌افزاری (`WinDivert`).
- **تستر ماتریس فایل‌های IP و SNI (روش اولیه پروژه):**
  - فایل‌های `ips.txt` و `snis.txt` برای تست تمام جفت‌های (IP × SNI) به روش اصلی پروژه.
- **تست پینگ و سرعت اختصاصی Google (Google x4):**
  - سنجش واقعی برقراری ارتباط از طریق درگاه SOCKS5 کلاینت شما (`127.0.0.1:10808`).
  - تست سریع (Quick Check) برای پیدا کردن فوری حالات متصل.
- **انتخاب و اجرای آنی:** با دابل‌کلیک روی هر ردیف، کانفیگ فوراً فعال و استارت می‌شود.
- **کراس‌پلتفرم (ویندوز و لینوکس):**
  - در ویندوز: کارکرد ترکیبی با درایورهای Npcap و WinDivert و اخذ خودکار مجوز ادمین (UAC).
  - در لینوکس: کارکرد پرسرعت در لایه سوکت و رله ترافیک با پشتیبانی کامل از CLI.

## 🛠️ ساختار استراتژی‌های بای‌پس

| مؤلفه | گزینه‌ها | توضیح |
| :--- | :--- | :--- |
| **Seq Offset** | `Classic (-len)`, `Seq -1` تا `-50K`, `Seq +1` تا `+1K`, `Seq = 0` | تغییر موقعیت شماره توالی بسته فیک نسبت به هندشیک سرور جهت فریب DPI بدون ایجاد تداخل در نشست |
| **Fake HTTP Probe** | `None`, `HTTP GET`, `HTTP HEAD` | ارسال درخواست ساختگی وب قبل از هندشیک TLS جهت سردرگمی طبقه‌بندی پروتکل |
| **Fake RST** | `فعال`, `غیرفعال` | ارسال بسته RST فیک جهت مسموم‌سازی جدول ردیابی اتصال DPI (State Poisoning) |
| **Driver Engine** | `Npcap (L2 Frame)`, `WinDivert (L3/L4 Filter)` | تزریق مستقیم فریم اترنت به کارت شبکه یا فیلتر هسته ویندوز |

## ⚙️ راهنمای استفاده سریع

### در ویندوز (Windows):
1. فایل زیپ را اکسترکت کنید.
2. روی **`run.bat`** دابل‌کلیک کنید (برنامه به صورت خودکار با دسترسی Administrator اجرا می‌شود).
3. در تب اول:
   - روی **`⚡ تست سریع`** بزنید تا حالات متصل پیدا شوند.
   - فیلتر را روی **فقط حالات متصل** بگذارید و **`⚡ تست پینگ`** بگیرید.
   - روی بهترین ردیف **دوبار کلیک** کنید تا سرویس استارت شود.
4. در تب دوم:
   - لیست IPهای سالم و دامنه‌های مجاز را در `ips.txt` و `snis.txt` ویرایش کرده و تست دسته‌جمعی بگیرید.

### در لینوکس (Linux):
```bash
tar -xzvf SNI-Spoofing-Linux.tar.gz
chmod +x sni-spoofing-linux
./sni-spoofing-linux --cli
```

## 🔌 تنظیم در v2rayN / v2rayA

کانفیگ `VLESS + WS + TLS` خود را ویرایش کنید:
- **Address:** `127.0.0.1`
- **Port:** `40443`
- سایر پارامترها (SNI و Host واقعی شما) بدون تغییر باقی می‌مانند.
- پورت خروجی SOCKS5 کلاینت را روی `127.0.0.1:10808` تنظیم کنید.
